# Two Robots in an Elevator

One line of awkward small talk a robot says to another in an elevator: 47 minutes of rehearsal, and the opening line is still "so, do you come here often?"

`main.py` writes the line to `entry.txt` in `MAKEFUN_OUTPUT_DIR` (default `/output`).
